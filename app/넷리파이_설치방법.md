# 블로그 공방 앱 — 넷리파이 설치 방법

이 폴더(app/)만 넷리파이에 올라가요. 카드뉴스 이미지·원고는 저장소에 그대로 있고, 앱이 바로 읽어 와요.

## 1. 사이트 만들기 (한 번만)
1. https://app.netlify.com 에 GitHub 계정으로 로그인
2. **Add new site → Import an existing project → GitHub**
3. 저장소 **ljh840125-sudo/maeumgil-cards** 선택
4. 설정 칸은 건드리지 말고 **Deploy** (저장소의 netlify.toml이 알아서 app 폴더만 올림)

## 2. 열쇠(환경변수) 넣기
Site configuration → Environment variables → Add a variable

| 이름 | 꼭? | 어디서 받나요 | 하는 일 |
|---|---|---|---|
| APP_PASSWORD | 꼭 | 직접 정하기 (예: 영문+숫자 10자 이상) | 남이 내 앱으로 AI를 못 쓰게 막는 비밀번호 |
| ANTHROPIC_API_KEY | 꼭 | console.anthropic.com → API Keys (유료, 쓴 만큼 결제) | 원고 쓰기 |
| PEXELS_API_KEY | 추천 | pexels.com/api (무료) | 빈 사진 자리에 무료 사진 자동 채우기 |
| OPENAI_API_KEY | 선택 | platform.openai.com → API keys (유료) | AI 그림, AI 대표이미지 배경 |
| NAVER_AD_API_KEY · NAVER_AD_SECRET · NAVER_AD_CUSTOMER_ID | 키워드 찾기에 꼭 | searchad.naver.com 로그인 → 도구 → API 사용 관리 (무료). 액세스라이선스 / 비밀키 / CUSTOMER_ID 세 개 | 연관 키워드·월 검색량 |
| NAVER_CLIENT_ID · NAVER_CLIENT_SECRET | 상위글 분석에 꼭 | developers.naver.com → 애플리케이션 등록 → 사용 API에 '검색', '데이터랩(검색어트렌드)' 추가 (무료) | 블로그 글 수·상위 3개 글 분석·12개월 추이 |

넣은 뒤 **Deploys → Trigger deploy → Deploy site** 한 번 눌러야 적용돼요.

## 키워드 찾기 쓰는 법
1. '키워드 찾기' 탭에서 주제를 넣고 내 블로그 수준을 고르기 (새 블로그일수록 검색량이 작은 쪽이 상위노출이 쉬워요)
2. 등급이 **황금·좋음**인 키워드의 [상위글 분석]을 누르면 지금 1~3위 글의 길이·사진 수·소제목 수와 12개월 추이를 보여줘요
3. [이 키워드로 상위노출 글쓰기]를 누르면 키워드·연관 키워드·목표 길이가 글쓰기에 채워지고, AI가 상위 글이 다루는 정보는 빠짐없이, 문장은 베끼지 않고, 작가 경험을 더해 써요

## 3. 휴대폰에 앱처럼 깔기
웨일에서 사이트 주소 열기 → 메뉴 → **홈 화면에 추가**. 처음 한 번 APP_PASSWORD를 넣으면 그 기기에 저장돼요.

## 비용 감각 (2026-10 기준, 정확한 금액은 각 사이트 요금표 확인)
- 원고 1편: Claude API 몇십 원 수준
- AI 그림 1장: OpenAI 이미지 수십~백몇십 원 수준
- Pexels 무료 사진: 0원
- 넷리파이 무료 요금제로 충분해요.

## 바꿀 수 있는 설정 (선택)
- ANTHROPIC_MODEL: 원고 쓰는 모델 (기본 claude-sonnet-5-5)
- OPENAI_IMAGE_MODEL: 그림 모델 (기본 gpt-image-1), OPENAI_IMAGE_QUALITY: low/medium/high

## 고칠 때
src.html을 고친 뒤 `python3 app/build_index.py`로 index.html을 다시 만들고 push.
